# DAW_LAB

A simulation system for post silicon lab work, works in real time. 
great for quick "issue reproduction" and training. 
this uses audio channels to mimic analog signal and vst format to mimic lab equipment such a scopes. 
currently available IP's are, DDR, SERDES and PLL.
